### Задача про календарь

Вопрос задачи: Сколько всего уникальных календарей существует вне зависимости от номера года?

Ответ: Число уникальных календарей = 14

#### Описание программы
Пользователь указывает номер года, программа отображает содержимое календаря, соответствующее введённому номеру года.
