### Задание про календарь

Сервис григорианского календаря (для годов начиная с 1600), реализованный на Spring Boot.

Возвращает календарь года или отдельного месяца в формате JSON или в виде готовой строки
(как в консольном варианте), а также умеет находить годы с аналогичным шаблоном
(тот же день недели 1 января и високосность).

Используется база данных PostgreSQL (поднимается в контейнере), реализован контроллер с валидацией входных данных,
сервис с основной логикой, реализована глобальная обработка исключений, эндпоинты задокументированы через Swagger.
